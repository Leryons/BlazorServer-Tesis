# Tesis

Proyecto Blazor ubicado en este repositorio. Contiene la aplicación web y los servicios auxiliares.

Instrucciones rápidas:

- Construir: `dotnet build`
- Ejecutar en desarrollo: `dotnet watch run` o `dotnet run`

Notas:
- La base de datos local `Services/Database.db` está listada en `.gitignore`.
- Añade credenciales y secretos en variables de entorno, no en el repo.
